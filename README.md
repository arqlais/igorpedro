# Primeiro Passo

Site e app de acompanhamento físico em quatro níveis (conhecer, em casa, ao ar livre, academia) para quem ainda não teve coragem de começar a treinar.

É uma página única (`index.html`), sem build e sem servidor. O progresso de cada pessoa fica salvo só no navegador dela (localStorage).

Para publicar: **Settings → Pages → Deploy from a branch**, escolha a branch e a pasta `/ (root)`.
